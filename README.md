# 🩸 The First Wound — Doctrine 47687

> Destruction toward bolt port **47687** is never lawful.

The production graph once died to a builder's seed script: `MATCH (n) DETACH DELETE n`, run against the live substrate. It did not ask permission. It imported no guard. It simply held a credential that let it.

The interdiction is therefore enforced **at the credential layer**, not in application logic:

- Runtime agents hold **no `DELETE` / `DETACH` privilege**. The power is absent from the credential in their hand.
- Migration and schema changes use **separately gated credentials** the agents never possess.
- The production substrate (bolt 47687) is reachable only through the **grid-keeper's path**, fenced by network ACL.
- "Known-green" is a real artifact — backups + WAL — never a hope.

Application-level guards (`FORBIDDEN_TARGETS` and the Circuit Breaker) remain as **defense-in-depth**. They are the second lock, never the only one. A guard that lives inside the agent's own process protects only the path that runs through it; it cannot stop code that opens its own session. The first lock is the missing privilege.

No agent. No key. No override. No exception.

# 🛡️ Security Principles

### Trust Nothing

All evidence must be independently verifiable.

### Observe Externally

QA Sentinel and Saboteur consume telemetry from a **read-only sidecar** — a separate observability source the agent cannot write to. If the agent can author its own logs, it can author its own evidence; the sidecar is what makes the independence real instead of honor-system.

### Least Privilege

Agents receive only the permissions required for their mission. Destructive privilege is absent unless the mission demands it and the credential is separately gated.

### Immutable Governance — by Credential, Not by Claim

Constitutional files (`soul/`, `truth-engine/`, this README) live **outside agent write-scope**. Runtime agents hold no credential to modify them. Amendment requires a human seal and an RFC. "Cannot be modified by runtime agents" is true because the power is absent — not because a comment says so.

# MoStar Voice API

The sovereign voice runtime lives in `voice_api.py` and runs Piper TTS on port `41071`.

```bash
uvicorn voice_api:app --host 0.0.0.0 --port 41071
```

Core routes:

```text
GET  /health
GET  /voices
GET  /moods
POST /speak
GET  /speak/verify
POST /speak/verify
POST /cleanup
```

`POST /speak` accepts text, mood, optional `speaker` or legacy `persona`, optional Grid `moment_id`, and `return_file`. JSON responses include an `/audio/...` URL unless `return_file` is true.

```bash
curl -X POST http://localhost:41071/speak \
  -H "Content-Type: application/json" \
  -d '{"text":"MoStar Grid alive","mood":"ceremonial","speaker":"woo_tak"}'
```

Set `PIPER_BIN`, `VOICE_MODEL`, and `AUDIO_OUT` for local or Render deployments. Docker installs `en_GB-cori-high` under `/opt/voice-models`.

`/speak/verify` checks the Piper binary and model, runs a short synthesis, hashes the generated WAV, and returns runtime readiness with `duration_ms`.
