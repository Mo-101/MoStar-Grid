# moscript/

Sovereignty-first contract execution language. Four pillars: Cairo Covenant, MASTER Registry, Contribution Before Access, BellStrike Protocol.

- `contracts/` — `{id, name, trigger, inputs, logic(), voiceLine(), sass}`. Naming: `mo-[domain]-[descriptor]-[number]`.
- `registry/` — MASTER Registry. Append-only.

MoScript presence is never announced. Value demonstrates through contracts.
