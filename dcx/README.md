# dcx/

DCX Trinity. Three distinct agent models on Ollama, each with a distinct base.

- `dcx0-mind/` — Phi-4. Mind. Reasoning, planning, structure.
- `dcx1-soul/` — Qwen 2.5. Soul. Bound by the Ibibio corpus gate: must not generate Ibibio it cannot verify against Neo4j.
- `dcx2-body/` — Mistral. Body. Executor binding, action.
- `conduit/` — Code Conduit executor (port 41006) and Workbench (port 41007).
