# soul/

The immutable layer. Doctrine, language, elements, canon. Everything downstream draws on this.

- `ibibio/` — native soul language. 405 words, tone patterns, audio links. **Source of truth for the entire MoStar ecosystem; downstream systems import from here.** See `soul/ibibio/README.md`.
- `odu/` — 256 Odù Ifá corpus.
- `elements/` — Ikang 🜂, Mmọng 🜄, Afim 🜁, Isong 🜃. Definitions and bindings.
- `canon/` — MoStar README canon, Cairo Covenant, Bell-Strike protocol, contribution-before-access rule.

**Rule:** changes to `soul/` are RFC-gated. No casual commits.
